# FastCore 管理端设计系统

> 本目录名称与项目品牌统一为 FastCore。当前视觉以 `frontend/src/styles/core/_fa-tokens.scss` 和实际页面组件为落地依据。根目录 `dashboard-beautify-preview.html` 仅保留早期 Quiet Operations 色板与布局草稿；其中的指标、趋势、活动和日志是静态示例，只有真实接口支持的数据才能进入产品页面。

## 产品与方向

- 面向企业后端骨架管理端的管理员和知识库、AI 对话使用者；页面首先帮助用户找到工作入口、读取真实状态并完成操作。
- 默认浅色界面使用淡蓝灰画布、白色面板和蓝色操作强调。层级依靠标题、间距、边框、玻璃表面与克制阴影表达；登录页、首页与 AI 对话可使用 Bento / Liquid Glass Token，管理列表保持更高信息密度。
- 深色模式和用户自选主题色继续可用。设置面板会在运行时更新 `--theme-color`，不能把默认蓝色写死在所有可交互控件上。
- 操作密集的表格和表单保持紧凑；首页保持克制，不用菜单数量、角色数量、会话自检等重复信息填满空间。

全站按应用外壳、管理列表、AI 工作区、身份与异常恢复四类落地。当前验收入口见[测试与验收](../../docs/TESTING.md)；历史证据见[UX 记录](../../docs/UX_IMPROVEMENT_TASKS.md)，全站回归脚本为 `frontend/tests/site-e2e.cjs`，不把样式继承或静态预览当成逐页验收。

## 颜色与主题

下表是当前默认值。新增页面优先使用语义变量，不复制十六进制颜色到组件内。

| 用途       | 浅色值    | 变量                        |
| ---------- | --------- | --------------------------- |
| 页面画布   | `#F4F6FB` | `--fa-color-canvas`         |
| 面板       | `#FFFFFF` | `--fa-color-surface`        |
| 次级表面   | `#F8FAFC` | `--fa-color-surface-raised` |
| 侧栏表面   | `#FFFFFF` | `--fa-color-sidebar`        |
| 选中背景   | `#EAF0FE` | `--fa-color-sidebar-active` |
| 默认强调色 | `#3B73E8` | `--fa-color-accent`         |
| 强调色悬停 | `#1F4FC4` | `--fa-color-accent-hover`   |
| 主要文字   | `#0F172A` | `--fa-color-text`           |
| 次要文字   | `#647387` | `--fa-color-text-muted`     |
| 边框       | `#E7ECF2` | `--fa-color-border`         |
| 成功       | `#0F9D77` | `--fa-color-success`        |
| 警告       | `#D98A16` | `--fa-color-warning`        |
| 危险       | `#E0514B` | `--fa-color-danger`         |

深色模式由 `html.dark` 覆盖表面层级：画布 `#0C0F15`、面板与侧栏 `#141922`、次级表面 `#181F2A`、文字 `#E7EDF5`、边框 `#232C39`。暗色选中背景为 `#1A2540`。菜单配色也受用户设置影响，因此单个已登录会话的侧栏颜色不代表默认值。

默认品牌色仍为 `#3B73E8`；浅色主按钮使用 `#3267D6` 配白字，深色主按钮使用 `#6F9BFF` 配深字。运行时保留自选主色，分别计算按钮文字和悬停文字，并将文字强调色调整到面板上至少 4.5:1；不把亮蓝色与白色文字直接配对。

边框分为表面分隔 `--fa-color-border`、强分隔 `--fa-color-border-strong` 和可识别控件边界 `--fa-color-control-border`。焦点使用独立 `--fa-color-focus`，次级按钮采用中性描边。危险按钮使用描边和淡底反馈，停用等中性状态仍可使用灰色。

状态淡底分别为浅色 `#E6F6F0 / #FBF1DE / #FCEBEA`、深色 `#11271F / #2A2011 / #2A1514`。浅色标签文字使用更深的 `#087456 / #8A570C / #B52F2A`；深色使用 `#2FCF9F / #E7A23C / #F0736E`，组件映射覆盖 Element Plus 的状态变量。

状态色只表示真实状态，并辅以文字或图标。普通操作使用 `--theme-color` 或现有语义变量；图表系列可以使用蓝色与成功色，但不能用颜色作为唯一图例。

## 字体、间距与表面

- 中文优先使用现有 `PingFang SC`、`Noto Sans CJK SC` 等本地字体回退；数据使用系统 `ui-monospace / SFMono-Regular / Menlo / Consolas` 回退栈及既有 `.fa-num` 等宽数字。预览稿引用的在线字体不作为运行依赖。
- 管理界面使用角色字号：页面标题 26px、区块标题 16px、正文与表单 13px、数据与表格 13px、说明 12px。长篇 AI 回答、图标和统计展示保留各自阅读与识别需要的字号。
- 间距以 4px 为基准；常用 8、12、16、20、24px。当前控制圆角 `10px`，面板和浮层圆角 `14px`，默认控件高度 `36px`。
- 面板使用 `--fa-color-border` 和 `--fa-soft-shadow`；浮层可使用更明显的 `--fa-overlay-shadow`。不在同一信息层连续嵌套卡片。
- 图标沿用现有 Remix/Iconify 体系。交互状态不能通过位移或缩放改变布局。

## 页面结构

### 应用外壳

- 侧栏按授权菜单分组，当前项同时通过背景、文字和图标突出。顶部栏只放全局工具和当前上下文；工作台标签保持稳定尺寸。
- 内容区桌面内边距当前为上 26px、左右 28px、下 40px；在 800px 及以下为 16px，在 640px 及以下为 12px。
- 800px 及以下固定侧栏占据左侧 64px，主内容须留出同宽空间，避免遮住标题或操作按钮。

### 首页工作台

- 首页优先呈现真实可访问的知识与 AI 入口，随后呈现常用管理入口和有登录日志查询权限时的近七日登录活动；不截断授权菜单。
- 登录活动显示成功登录和新增账号摘要，并用真实接口数据绘制成功登录、独立用户趋势；保留加载、无数据和请求失败提示。无该权限时不显示趋势卡。
- 基础服务状态使用紧凑文字入口并支持刷新；数据库、Redis 等依赖异常或检查不可用时，显示具体说明和重试动作。
- 没有可用入口且看不到趋势时，明确提示联系管理员分配权限。首页不重复展示账号资料、角色和权限计数、模块数量或会话自检清单。
- 900px 及以下将趋势与快捷入口纵向排列；手机视图不能横向溢出或被侧栏遮挡。

### 管理与 AI 页面

- 列表页按标题、紧凑筛选、主要操作、表格与分页组织；宽表格在小屏上保留识别字段并提供可用的横向访问方式。
- 表单的校验紧邻字段，危险操作说明对象和影响；加载、空结果、无权限、失败各有清晰文字。
- 引用列表和检索结果以 2px 左侧细线、系统等宽来源编号表达出处，不再嵌套结果卡片。只显示实际存在的文档和分块；分块保留接口的零基编号。向量距离、BM25 得分、融合得分按实际检索模式显示，不解释为置信度或页码。AI 页面沿用共享颜色和表面变量；检索、生成、引用和失败状态应来自实际业务数据，不套用预览稿的演示内容。

## 交互与可访问性

- 控件反馈约 120ms，页面切换约 200ms；尊重 `prefers-reduced-motion`，主题切换在 JS 入口直接切换，在 CSS 层禁用视图过渡动画。
- 键盘焦点清晰可见；图标按钮有可读名称；状态同时由文字或图标表达，不能只靠颜色。
- 正文和背景应有足够对比度；检查亮色、暗色以及自选主题色下的状态。
- 页面布局在 375px、768px、1024px、1440px 检查无重叠、裁切和意外横向滚动。768px 及以下的主要控件采用至少 44px 触控高度；表格内部横向滚动不等于页面溢出。
- 小屏管理表格保留明确的可滚动高度，避免百分比高度在自动高度容器中塌陷；分页使用前后页和总数，避免多页页码按钮被裁切。桌面完整分页及调用方配置保持可用。
- AI 对话按真实可用视口约束工作区，输入区保持可见；没有依据时不占用独立第三栏，紧凑宽度通过抽屉读取来源。

## 实现与验收入口

- 颜色、圆角、间距和阴影：`frontend/src/styles/core/_fa-tokens.scss`。
- 字体与排版：`frontend/src/styles/core/_fa-type.scss`。
- 应用外壳：`frontend/src/components/layouts/_fa-layouts.scss` 与侧栏、顶部栏组件。
- Element Plus 映射与深色表面：`frontend/src/styles/element-plus/`。
- 首页信息层级：`frontend/src/views/home/`。
- 样式入口与开发命令：`frontend/src/styles/README.md`。

修改视觉规范后，对照上述实现入口核对变量和页面；修改页面后运行目标文件的格式、样式检查，以及适用的类型检查、测试、构建，并在浏览器检查真实数据、交互、空态和窄屏。文档描述当前约定，不以历史预览稿里的静态数字或构图充当验收证据。
